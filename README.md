## محدوده بکاپ فعلی

| بخش | وضعیت بکاپ |
| --- | --- |
| سورس فرانت‌اند | کامل؛ کدهای `src/`، فایل‌های تنظیمات، وابستگی‌ها و دارایی‌های تصویری در Git ثبت شده‌اند. |
| سورس بک‌اند | در نسخه فعلی این ریپو هیچ پیاده‌سازی بک‌اند یا فایل سروری وجود ندارد؛ فقط وابستگی Express در `package.json` ثبت شده است. |
| دیتابیس | در نسخه فعلی هیچ فایل دیتابیس، اسکیما، migration یا dump قابل بکاپ وجود ندارد. |
| خروجی بیلد و secrets | عمداً در بکاپ سورس نیستند؛ `dist/`، `node_modules/` و فایل‌های `.env` طبق `.gitignore` کنار گذاشته شده‌اند. |
